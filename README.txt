MAXIMILIAN FONA — PORTFOLIO SOURCE

Open index.html in your browser. Keep these files in the same folder.
No package installation or build step is required.

index.html       Page structure, résumé content, and project cards
styles.css       Layout, themes, responsive styles, and animations
preferences.js   Applies saved theme/motion preferences before the first paint
script.js        Navigation, search, animation controls, and local notebook
Maximilian-Fona-Resume.pdf   Original supplied résumé, unchanged

Edit text and project cards in index.html; adjust appearance in styles.css.
Keep preferences.js in the document head before the stylesheet so saved
preferences are applied without a theme flash. script.js loads at the end.

To host the page, upload all six files together to a static web host.
For a single-file alternative, use the previously supplied
Maximilian-Fona-Portfolio.html; it embeds its styles, scripts, and résumé.

The notebook saves notes in browser localStorage. Storage for file URLs
varies by browser; moving files or changing hosts may use a new storage area.
Export notes before moving the site. Notes do not modify the HTML or publish.
